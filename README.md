## Selected Work

### `01` NovaStage

> **REAL-TIME COLLABORATION · CONCURRENCY · GRAPH ALGORITHMS**

A multiplayer workflow canvas built for concurrent editing and low-latency presence.

- Designed exclusive edit locks with 60-second lease heartbeats and peer handoff requests to prevent conflicting milestone updates.
- Built a custom DAG auto-layout with DFS cycle detection and graph validation.
- Added delta-time cursor interpolation and velocity prediction for smoother real-time collaboration.
- Protected public endpoints with Upstash Redis sliding-window rate limiting and an in-memory fallback.
- Validated behavior with **170+ automated tests** across 24 Vitest suites.

### `02` Barnicoat Branding CRM

> **MULTI-TENANCY · POSTGRESQL SECURITY · WEBHOOK INTEGRATIONS**

A multi-tenant operations CRM designed around database-enforced authorization.

- Enforced role and permission boundaries in PostgreSQL through Row-Level Security, preventing cross-tenant data access.
- Built rate-limited webhook ingestion for ManyChat and Calendly integrations, including standards-compliant retry responses.
- Created SQL views and stored procedures for commission tiers, editor margins, and funnel conversion reporting.
- Generated PDF and ZIP reports in the browser with jsPDF and JSZip, reducing server-side reporting overhead.
